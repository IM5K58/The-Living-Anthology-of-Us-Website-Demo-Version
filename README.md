# 살아있는 우리들의 시집 (The Living Anthology of Us)

###  [체험해보기](https://our-living-poetry.com)

> *"당신의 일상과 감정이 모여, 하나의 아름다운 시집이 됩니다."*

**'살아있는 우리들의 시집'** 은 누구나 자유롭게 자신의 생각과 감정을 시로 쓰며, 다른 사람들이 남긴 시를 읽고 공감할 수 있는 편안한 온라인 시집 플랫폼입니다.

## 서비스 소개
바쁜 일상 속에서 잠시 멈춰 서서 내면의 목소리에 귀 기울일 수 있는 아늑한 휴식처를 지향합니다.
거창한 문장력이 없어도 괜찮습니다. 당신이 지금 느끼는 솔직한 감정들을 한 편의 시로 남겨보세요.

**데모 버전 기능**
- **시 작성하기:** 캔버스처럼 깔끔하고 감성적인 에디터를 통해 나만의 시를 자유롭게 창작할 수 있습니다. 
- **시 모아보기:** 다른 사람들이 마음을 담아 써 내려간 다채로운 시들을 한곳에서 둘러보며 영감과 위로를 얻습니다.
